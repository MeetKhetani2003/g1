# G1 Images

Phase 1 uses curated remote healthcare photography (Pexels CDN) for hero and
service cards to keep the single-file preview lightweight and fast.

Local brand assets live in `/brand/`, reusable glyphs in `/icons/`, and
decorative SVG illustrations in `/illustrations/`.

All remote images include descriptive alt text and CSS fallbacks so the layout
remains intact if a CDN image is unavailable.
